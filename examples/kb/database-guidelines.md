# 数据库与 SQL 规范

## 查询

- 禁止 `SELECT *`，明确列出需要的字段，减少传输和隐藏的列变更风险。
- 大表查询必须有合理的 WHERE 条件和索引，避免全表扫描。
- 分页查询用 `LIMIT/OFFSET` 或游标，避免一次拉取全部数据。

## 索引

- 高频查询字段建立索引；但不要盲目加索引，索引会拖慢写入。
- 复合索引遵循最左前缀原则，把区分度高的字段放前面。
- 避免在索引列上做函数运算或隐式类型转换（会导致索引失效）。

## 事务与一致性

- 涉及多个写操作的业务用事务包裹，保证原子性。
- 事务尽量短，不要在事务里做网络调用或长时间 IO。
- 注意隔离级别与并发问题（脏读、不可重复读、幻读），必要时用悲观锁/乐观锁（version 字段）。

## 数据设计

- 字段选合适类型，金额用 DECIMAL 而不是浮点数，避免精度丢失。
- 外键、唯一约束尽量在数据库层保证，不能只靠应用层校验。
- 软删除字段、创建时间、更新时间等公共字段统一约定。

## 批量操作

- 批量插入用批量接口，不要逐条提交。
- 大批量更新分批执行，避免长事务和锁表。
